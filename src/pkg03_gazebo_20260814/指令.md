需求	命令
恢复所有文件到上次 commit 的状态	git restore .
只恢复某个文件	git restore 文件路径
查看当前修改了哪些文件	git status
查看具体修改了什么内容	git diff
⚠️ 这会丢弃所有未提交的修改，操作前建议先用 git diff 确认一下改动内容。

git reset --hard HEAD~1  删除最近的一条提交
git rebase -i <commit_id>  删除指定的某一条提交（保留其他）
git log --oneline -1   # 记住当前最新提交的信息
git reset --soft <最早想保留的提交id>   # 回退到某个版本，但保留所有文件
git commit -m "合并多次提交为一个"        # 重新提交一次
