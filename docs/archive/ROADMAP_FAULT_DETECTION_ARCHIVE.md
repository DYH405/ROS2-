## b. 原规划全文（原样保留，不改写、不删减、不重排）

> 以下内容逐字取自 `HANDOFF.md` 第五节（第 228–277 行）。原文在该文件中**未被删除、未被修改**，仅在其后增加一行指针。

### 原第五节标题与课题核心

> 课题核心：**面向室内巡检任务的ROS2移动机器人故障检测与分级恢复，并通过不确定性仿真和回归实验进行验证。**

### 第二阶段：分层注入不确定性

| 类别 | 注入内容 | 观察指标 |
|:---|:---|:---|
| 控制/底盘 | 轮速比例误差、响应延迟 | 轨迹误差、到点误差 |
| 里程计 | 噪声、比例误差、短时跳变 | odom漂移、定位偏差 |
| 雷达 | 延迟、丢帧、数据停更 | AMCL协方差、导航状态 |
| 负载 | 质量和重心变化 | 运动误差、成功率 |

### 第三阶段：故障检测与分类

- Topic超时：多久无新消息才报警
- TF超时：查哪对坐标系，等多久
- 有命令无运动：比较 /cmd_vel 与轮速/里程计变化
- 雷达异常：消息超时、有效点比例过低
- 里程计跳变：速度/加速度是否超出合理范围
- 定位异常：协方差阈值 + 连续N次超限

### 第四阶段：分级恢复与安全边界

- 雷达短时中断 → 停车等待恢复
- 代价地图异常 → 清理局部代价地图 + 重新规划
- 有命令无运动 → 停车 + 限制重试次数
- TF/里程计丢失 → 保持停止，不盲目后退
- 定位协方差异常 → 停止任务 + 等待重新定位

### 第五阶段：自动化回归与结果对比

| 编号 | 注入条件 | 预期行为 | 指标 |
|:---|:---|:---|:---|
| T01 | 正常导航 | 到达目标 | 成功率、误差、耗时 |
| T02 | 雷达停止发布 | 报警并停车 | 检测时间、误报 |
| T03 | 里程计停止发布 | 取消导航并停车 | 停车时间 |
| T04 | 轮速偏差10% | 误差上升 | 误差变化 |
| T05 | 有命令无运动 | 判定卡滞并停车 | 检测率、误报 |
| T06 | 故障短暂恢复 | 有条件恢复 | 恢复成功率 |

### c.7 边界专节：研究内容 4 的「暂停/取消/超时/重试/跳过」 vs P3/P4

研究内容 4 第 3 条原文（L182）：「设计任务暂停、取消、超时、重试和跳过机制」。该条与 P3/P4 都含「异常处理」语义，必须划清边界。

| 维度 | 研究内容 4（暂停/取消/超时/重试/跳过） | P3 故障检测 | P4 分级恢复 |
|:---|:---|:---|:---|
| 作用对象 | 单个导航目标（goal） | 数据流与传感器（topic / TF / odom / scan / covariance） | 机器人整体安全状态 |
| 触发依据 | Action 状态机返回（rejected / canceled / timeout） | 数据特征（停更时长、单步跳变幅度、协方差阈值） | 故障分类结果 |
| 是否需知道「故障是什么」 | **不需要** | 需要（要分类） | 需要（分级建立在分类之上） |
| 动作粒度 | 放弃该点继续下一个 / 重试该点 | 报警、留痕 | 停车等待、清代价地图、限重试、保持停止、停任务待重定位 |
| 当前实现状态 | **已实现**（`partol_node.py`：`nav_fail_action: skip`、rejected 不重试、timeout/canceled/rejected 独立计数、5 项等式） | **未实现**（仅离线事后判定，见 `summarize_baseline.py` 四条 invalid 规则） | **未实现** |
| 开题报告位置 | 研究内容 4 第 3 条（L182），明确要求 | 无 | 无 |

**边界结论**：研究内容 4 覆盖「任务级异常处理」，P3/P4 覆盖「系统级故障诊断与安全降级」。两者共用「异常处理」字样但对象层级不同——研究内容 4 的机制不依赖故障分类即可动作，P4 的「分级」必须依赖 P3 的分类。故 P3/P4 无法并入研究内容 4，只能作为其异常处理能力的深化扩展。

**若把本归档内容当主线推进，会与开题报告主线产生以下冲突：**

1. **主线冲突（技术线不同）**。开题报告主线是「仿真→实物迁移 + 多传感器融合定位」（L21、研究内容 3），P2–P5 是「注入→检测→恢复→回归」，属另一条技术线。并行推进将挤占实物迁移的调试时间，而实物迁移是开题明确要求且需硬件在场。

2. **工期冲突（周次塞不进）**。开题报告进度安排把 2027 学年第 2 学期第 1–3 周给实物驱动配置与标定（L301–L304）、第 4–6 周给仿真与实物对比实验及中期检查（L309–L312）。P2–P5 至少需「注入→检测→恢复→回归」四段实验，每段 N≥10，现有周次无法容纳。

3. **指标口径冲突**。现有基线指标（valid 率、导航成功率、`pos_err`、`yaw_err`、耗时）为「正常导航重复实验」设计；P2–P5 需「检测时间、误报率、恢复成功率」另一套指标。混用会导致论文数据表口径不一致、结论不可比。

4. **课题名冲突**。开题报告题目不含「故障检测与分级恢复」字样（见 a.2 原因二对照表）。若将其作为主线，存在开题变更风险，需先与指导教师确认。

5. **样本量风险**。当前 P1 基线实测定位可信率为 46.7%（7/15），跳变落点集中于 wp3（n=4 中 3 次）。P3 若以「定位偏差」为主要检测对象，其报警阈值必须建立在更大样本上，否则误报率不可信。

> **时点标注**：本条数据取自 2026-11-07 基线采集**进行中**的中间值（当时 valid=7，目标 N=10），非最终结果。N=10 收尾后该数字会变化，届时以 `experiment_logs/baseline_report.md` 为准。本条只作量级参考，不作为 P3 阈值设定依据。
